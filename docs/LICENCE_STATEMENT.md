# PARIKSHAK — licence and data statement

SIH 2026 · PS 26174 · Space Technology · status as of 17 September 2026

## The sentence for the slide

> PARIKSHAK ships no trained weights and no third-party dataset. Its procedure
> engine, simulator, synthetic evaluation corpus and printed-marker perception
> are our own work. Every runtime library is used under a permissive licence
> (Apache-2.0, MIT, BSD, MPL-2.0), except the Qt desktop window, which uses
> PySide6 under the LGPL, dynamically linked. When a detector is trained, its
> delivered weights will come only from our own recordings, MicroG-4M (MIT),
> IndustReal (Apache-2.0) and synthetic renders; CC BY-NC datasets will be used
> for benchmark reporting only, never in a delivered model.

## What ships today

| Component | Origin | Licence |
|---|---|---|
| Procedure engine, belief format, alert policy, run log (`parikshak/`) | Written for this project | Ours — licence to be chosen with the repository (recommended: Apache-2.0) |
| Procedure files CSP-1 and CRX-2 (`procedures/`) | Written for this project | Ours |
| Evaluation traces, golden traces (`traces/`) | Generated by our simulator (`tools/make_golden_traces.py`, `tools/make_eval_corpus.py`) | Ours — no recorded footage of any person |
| Printed rack and prop markers (`runs/tags`) | AprilTag `tag36h11` family, generated with OpenCV | Tag family is a published open standard; the sheets are ours |
| Trained model weights | **None exist yet** | — |

## Runtime libraries actually imported

Checked against the installed packages' own metadata and against the imports in
`parikshak/` — not from memory.

| Library | Version checked | Licence | Used for | Required? |
|---|---|---|---|---|
| NumPy | 2.5.1 | BSD-3-Clause (with 0BSD, MIT, Zlib, CC0 parts) | Geometry, everywhere | Yes |
| PyYAML | 6.0.3 | MIT | Reading procedure files | Yes |
| jsonschema | 4.26.0 | MIT | Validating procedure files | Yes |
| OpenCV (`opencv-contrib-python`) | 5.0.0 | Apache-2.0 | Camera, AprilTag detection, pose, video | Live runs, reel |
| PySide6 (Qt for Python) | 6.11.2 | LGPL-3.0-only (or GPL-2.0/3.0) | Desktop operator window | Desktop GUI only |
| pyttsx3 | 2.99 | MPL-2.0 | Spoken prompts and alerts | Voice only |
| FastAPI | 0.137.0 | MIT | Browser demo server | Web demo only |
| Uvicorn | 0.49.0 | BSD-3-Clause | Browser demo server | Web demo only |
| httpx | 0.28.1 | BSD-3-Clause | Tests of the web demo | Tests only |

**PySide6 is the one to explain if asked.** LGPL-3.0 allows use in closed or
open software provided PySide6 is dynamically linked and can be replaced by the
user — which is how it is used here (an unmodified pip package, imported at
runtime). A flight build that does not want the obligation can drop the Qt
window: the engine, voice, log and web demo do not import it.

**Optional back-ends that the code can load but that are not installed or used
today:** ONNX Runtime (MIT), MediaPipe (Apache-2.0), pupil-apriltags (BSD-2),
Vosk (Apache-2.0). Each is imported only inside the back-end that needs it.

## Datasets — the rule for when models are trained

From PLAN.md §11.5, unchanged:

| Licence | Datasets | May it touch delivered weights? |
|---|---|---|
| MIT | MicroG-4M | Yes |
| Apache-2.0 | IndustReal | Yes |
| CDLAv2 | HoloAssist | Yes |
| CC BY-NC 4.0 | Assembly101, IKEA-ASM, HOI4D, DexYCB | **No — benchmark reporting only** |
| Unstated | MECCANO | Not until the authors confirm |

A fielded ISRO system is not obviously "non-commercial", so the conservative
reading is the one we commit to.

## Before the repository is made public

1. Choose and add the project's own licence file (recommended: Apache-2.0,
   matching OpenCV and giving an explicit patent grant).
2. Keep this table current: re-run the metadata check whenever a dependency is
   added —
   `python -c "from importlib import metadata as m; print(m.metadata('PACKAGE')['License-Expression'])"`.
3. Record the source and licence of every dataset in `datasets/README` before its
   first download, not after training.
