          The ideas that make it trustworthy
          
    
          
      
          The procedure is a file
          Steps, objects, zones and safety rules are written in a procedure file. A new experiment is a new file — the second experiment here needed no retraining and no code change.
          
      
          Unknown is not wrong
          If the crew's body blocks the camera, the step reads "cannot verify", never "skipped". An alarm needs evidence against the step, not missing evidence.
          
      
          Every alert has a reason
          "Step eight, close the glovebox latch, was not completed" comes with the condition that failed and when. A reviewer can check every decision.
          
      
          Up is the rack, not gravity
          Positions are measured against markers on the rack, so rotating the rack or floating upside down changes nothing the engine reasons with.
          
      
          Offline and auditable
          No network code in the on-board software. Each run writes a hash-chained log: change one byte and verification names the record that was altered.
          
      
          Beyond sequence: safety
          Opening the latch while the unit runs skips no step, so a checklist cannot see it. A safety rule that must hold throughout the step catches it.

          Honest limits
          
    
          
      
          Synthetic data
          The evaluation runs are generated and degraded, not recorded on orbit or in a lab. Real footage will be harder.
          
      
          No trained models yet
          Objects are seen through printed markers. Without hand tracking, a live webcam run cannot verify steps that need hands and waits at the first one — without raising a false alarm.
          
      
          Edge hardware
          Speed is measured on a laptop CPU only. The target of at least 10 frames per second within 25 W needs a Jetson and a power meter.
          
      
          Rushed steps behind a blind spot
          If the camera was blocked just before a rushed step, the engine gives the crew the benefit of the doubt, and can miss it.
